# Research basis and limits

The signal list is a diagnostic adaptation of the supplied Charles Liu notes, not an independently verified transcript or a universal standard. FORM's applications below are original synthesis. No competitor skill code, paid course content, or full third-party article is bundled.

| Primary source | Supported lesson | Application boundary |
| --- | --- | --- |
| [NN/G: Aesthetic and minimalist design](https://www.nngroup.com/articles/aesthetic-minimalist-design/) | Remove irrelevant competition while preserving necessary information. | Useful minimalism does not require a minimalist visual style. |
| [NN/G: Visual hierarchy](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/) | Emphasis and grouping direct attention. | Inspect the actual reading path rather than counting visual features. |
| [NN/G: Five visual-design principles](https://www.nngroup.com/articles/principles-visual-design/) | Scale, hierarchy, balance, contrast, and grouping work together. | A rule applied without context can defeat another relationship. |
| [GOV.UK: Tag component](https://design-system.service.gov.uk/components/tag/) | Status tags can carry necessary information; static status and interaction should be distinguishable. | This is a functional counterexample to banning pills, not a requirement to copy GOV.UK styling. |
| [NN/G: Flat-design best practices](https://www.nngroup.com/articles/flat-design-best-practices/) | Removing visible signifiers can make actions uncertain. | Simpler appearance must preserve discoverability. |
| [Every Layout: Axioms](https://every-layout.dev/rudiments/axioms/) | Design constraints should accommodate fluid content and user settings. | Fixed screenshots do not establish responsive behavior. |
| [W3C: Text spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html) | Text-spacing overrides should not cause loss of content/functionality. | The override values are not mandatory authored tracking or leading. |
| [W3C: Use of color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html) | Color alone must not carry required meaning. | A sophisticated palette does not replace labels or other cues. |
| [Adobe Spectrum: Typography](https://spectrum.adobe.com/page/typography/) | Type has differentiated roles and language/reading needs. | A named family is not an intrinsic quality problem or a universal replacement. |
| [Reinecke et al.: Predicting website aesthetics](https://www.iis.seas.harvard.edu/papers/2013/reinecke13aesthetics.pdf) | Complexity/colorfulness relate to first-impression judgments; preferences are not universal. | First impressions in the paper's study do not establish task success or a universal slop detector. |

Sources checked 2026-11-03. Browser observations and aesthetic judgments have different certainty. A computed-style sample establishes a measured property of that page, not whether the property is appropriate. FORM does not claim to outperform another skill based on document comparison or package tests.
