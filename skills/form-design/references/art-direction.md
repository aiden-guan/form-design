# Art direction that changes the outcome

Use this when the brief is open, the result feels interchangeable, or references are pulling in conflicting directions.

## Find specificity in the subject

Extract material from the actual project: its objects, vocabulary, geography, people, process, output, or emotional context. A ceramic studio has clay edges, kiln marks, glazes, scale, and an appointment rhythm. A developer tool has traces, diffs, execution order, and precision. These suggest different visual relationships before any trend is chosen.

Write a thesis that predicts visible choices. “Premium and modern” does not. “Oversized photographic contact sheets with precise inventory captions” does: image-dominant composition, typographic contrast, repeated registration, controlled density.

Choose a few tensions to resolve:

| Axis | Questions that affect the design |
| --- | --- |
| Quiet ↔ expressive | Does the audience need calm repetition, an emotional entrance, or both in different areas? |
| Editorial ↔ instrumental | Is the primary act reading a story, comparing evidence, or operating a tool? |
| Flat ↔ physical | Would depth clarify an interaction or just add visual noise? |
| Precise ↔ organic | Does the subject call for measured alignment, irregular material, or a deliberate relationship? |
| Dense ↔ spacious | How much information must someone compare at once? Where does space aid comprehension? |
| Familiar ↔ surprising | Which conventions must stay recognizable? Where can the project afford novelty? |

Changing every axis produces incoherence. Find a dominant language and use contrast selectively.

## Create different directions, not different skins

For exploration, vary the structure and information emphasis before the palette. Example for an architecture practice:

- **Archive:** project index first, strict captions, project photography in consistent ratios; supports efficient comparison.
- **Monograph:** one project at a time, generous reading space, drawings integrated with text; supports depth and authority.
- **Spatial invitation:** one immersive image and a location-led entry, then clear project navigation; supports atmosphere and discovery.

Choose using the brief. An archive may be the strongest answer even if an immersive concept looks more spectacular in a thumbnail.

## Turn a direction into an executable contract

Keep this compact enough to guide actual decisions:

```text
Audience / task:
Content and primary action:
Visual thesis and reason:
First focal point → second → action:
Layout relationships and mobile transformation:
Type roles and rationale:
Semantic colors and contrast pairs to check:
Image subject, crop, treatment, and source:
Signature detail and its job:
Behavior, important states, and motion fallback:
Existing constraints to preserve:
```

Only record fields relevant to the assignment. Store a durable brief or token file when the project needs a handoff; avoid creating ceremony for a small edit.

## Compose a reference set by role

One reference can inform the information hierarchy; another, the photographic treatment; another, a specific transition. Record those roles so they do not compete. Inspect their original visuals and behavior where available. Separate observed behavior from a proposed implementation.

Transfer relationships: relative scale, rhythm, density, image-to-text balance, state continuity. For an original design, invent the actual identity and composition for the new content. For a requested faithful match, measured source values take priority over reinterpretation.

## Diagnose a generic result

| Symptom | More effective correction |
| --- | --- |
| The project name could be swapped without changing anything | Introduce the subject's real content, vocabulary, imagery, or workflow into the central composition. |
| A giant headline, floating mockup, and repeated equal cards carry every section | Rebuild the information structure around narrative, evidence, comparison, or task flow. |
| It needs more “wow” | Check hierarchy, crop, contrast, and proportion before adding effects. Make one consequential relationship stronger. |
| Every element tries to be the signature | Establish a dominant focal point and lower the contrast or motion of supporting elements. |
| The moodboard has no coherence | Assign references explicit roles; remove those with incompatible spatial or material logic. |
| It feels fashionable but unrelated | Explain how each major choice expresses the project. Replace the ones supported only by trend. |

No font, gradient, grid, border radius, or color is inherently forbidden. The problem is an unexamined default repeated regardless of context.
