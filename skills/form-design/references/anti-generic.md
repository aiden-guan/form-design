# Diagnose generic design without imposing another template

Use this for a generic first draft or an “unslop” request. The complete, separately installable diagnostic workflow lives in FORM Unslop; this reference keeps the main design skill useful on its own.

## Look for the cause

An interface reads as interchangeable when the same visual recipe survives unchanged after swapping its project name and content. Inspect its reading path, information structure, imagery, voice, and interaction model before tweaking decoration.

Common symptoms include undifferentiated cards, status-shaped labels with no status, tiny faded text everywhere, italic accents with no emphasis to express, or a diagram that repeats a nearby paragraph. They are candidates for investigation, not proof of AI authorship.

For each candidate ask:

1. What job does it do for this audience or subject?
2. Is that job already done by another element?
3. Would removal make the task, hierarchy, navigation, accessibility, or intended expression worse?
4. Is it explicitly chosen by the user or an approved reference?

Keep an element when its job is clear. Change the composition when that is the actual problem. A font blacklist and a count of borders do not answer these questions.

## Repair with a specific move

| Cause | Better move |
| --- | --- |
| Every section has equal weight | Establish a reading path and change relative emphasis, grouping, or section structure. |
| Decorative pills repeat the heading | Remove the redundant label; preserve real filters and status indicators. |
| Bordered containers obscure relationships | Use spacing and alignment for simple grouping; retain fields, tables, and boundaries that convey a useful region. |
| The design has no subject-specific material | Use actual work, product evidence, vocabulary, imagery, or process to shape the central composition. |
| “More detail” became an invented interface | Replace fake controls and micro-labels with honest evidence; keep necessary complexity in working tools. |
| A font/color choice feels arbitrary | Compare a few alternatives on the same real content, then implement the selected roles. |
| Copy is long without adding information | State the fact and next action once. Preserve necessary legal, technical, and recovery information. |

## Do not overcorrect

Pills can encode status or filters. Monospace can make code meaningful. A border can identify an input. A dense screen may support skilled comparison. A serif can be exactly right for an established brand. Short uppercase labels, numbering, gradients, and punctuation can have real jobs. Dithering is deliberately outside this checklist; assess it only for a separately demonstrated problem such as legibility or rendering cost.

After a repair, operate the primary task and review the same state/viewport as the original. Check that useful meaning survived. End with the concrete changes, the significant choices preserved, and what remains unverified; do not report a fictional “AI-slop score.”
