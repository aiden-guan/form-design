# Make the decision visible

## A real-content specimen

For typography, include the actual project name, a representative headline, body copy, a navigation label, the longest plausible name, a sentence with punctuation, and relevant numeric/technical content. Compare available weight/width styles, language coverage, fallback behavior, and font licensing. Do not quietly substitute an unavailable font and label it as the requested one.

For color, show semantic roles together: text on canvas and surface, action/hover/focus, selected/unselected, status/error, and any relevant chart encoding. Test actual contrast combinations, including the worst relevant part of gradients or images. A palette card alone cannot establish interface suitability. Use labels or other cues in addition to hue where meaning matters.

For composition, show enough real content to expose hierarchy and rhythm. A dramatic opening with no second section is incomplete evidence for a whole-page direction. For a product view, include the task and its populated/empty/error states as relevant. For a native surface, preserve platform navigation, text scaling, safe areas, and reachable controls.

## Name the variable and its cost

| Question | A useful comparison | A misleading one |
| --- | --- | --- |
| Which type voice suits the journal? | The same article and navigation in two role systems, at reading size and on a phone. | Different fonts on unrelated headlines in different layouts. |
| Which palette supports booking? | The same session selector, selected date, primary action, and error using each palette. | Attractive swatches without text/control roles. |
| Which direction fits a maker's portfolio? | Archive-led, project-story-led, and image-led compositions with the same actual work and contact action. | Three accent colors on the same hero-and-card scaffold. |
| Can we mix the choices? | The chosen type and palette implemented together, with adjusted role metrics if needed. | Assuming two individually good options combine without checking. |

An alternative can be quieter, denser, more editorial, or more expressive for a reason. Do not make “more premium” the only axis. A work tool may win through scanability and familiar controls; an exhibition may win through an expressive image sequence. Explain the tradeoff the audience will experience.

## A compact decision receipt

Use an existing context document where available. Otherwise create a small note only when the handoff needs it:

```text
Decision / audience / task:
Factual content and constraints held constant:
Alternatives and tested differences:
Selected by user / selected by agent under instruction:
Type roles + available files/fallbacks:
Color roles + actual values:
Composition, image, and behavior rules:
Checks performed and conditions:
Unresolved assets or questions:
```

Keep rejected directions as rejected evidence when useful; never treat them as approved instructions. Do not overwrite facts in another document merely to tidy the handoff.

## Research basis

- [Jason Santa Maria: On Web Typography](https://alistapart.com/article/on-web-typography/) supports treating font choice and pairing as design decisions in context.
- [Refactoring UI: Building Your Color Palette](https://refactoringui.com/previews/building-your-color-palette) supports usable role/shade ranges beyond a few attractive swatches.
- [NN/G: Recognition and recall](https://www.nngroup.com/articles/recognition-and-recall/) supports making choices inspectable instead of requiring someone to imagine an aesthetic from abstract adjectives.
- [Every Layout: Composition](https://every-layout.dev/rudiments/composition/) supports reusable relationships that adapt to content.
- [W3C: Use of color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html) and [text spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html) establish functional constraints that style selection must accommodate.

The workflow is FORM's original synthesis. It is not copied from another skill and does not establish that a particular number of options or aesthetic direction is universally optimal.
