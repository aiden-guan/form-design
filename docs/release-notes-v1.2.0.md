# FORM Design v1.2.0

The owner rejected the first examples for decorative indicator lights, arrow glyphs, exaggerated italics and other unslop tells. This release applies the full checklist before implementation and delivery, corrects the examples, and retains the rejected drafts.

- Start without ornamental lights, ordinary-action arrows, italic accents, pills, eyebrows and other unsupported defaults. Preserve necessary meaning and explicit user choices.
- Review all 19 signals, artwork and pseudo-elements; an aesthetic genre does not justify decoration.
- Allocate the opening view to the surface's real use frequency; consolidate repeated framing while preserving character and useful labels.
- Inspect coupled text and controls under enlargement: adjacent columns can collide even when the page itself fits.
- Recheck the same affected relationship after fixing it, with long real labels and relevant states.

The three independent skills remain available through:

```sh
npx skills add aiden-guan/form-design
```

The [corrected-output record](https://github.com/aiden-guan/form-design/blob/main/evals/paired-2026-11-03/results.md) retains original fictional briefs, rejected drafts, four corrected interfaces, actual captures, task/style checks and cross-reviews. It distinguishes fresh drafts, guided repairs and continued-context work. Functional success alone did not pass visual acceptance.
