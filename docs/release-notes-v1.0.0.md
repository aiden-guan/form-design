FORM Design is a portable Agent Skill for designing distinctive websites, apps, and interfaces, from art direction through implementation and review.

Install with:

```sh
npx skills add aiden-guan/form-design --skill form-design
```

Or download **form-design.zip**, extract it, and place the complete folder in your agent's skills directory. See the [installation guide](https://github.com/aiden-guan/form-design#install).

Included:

- Workflows for original designs, redesigns, exploration, reference matching, and critique.
- Guidance for typography, composition, color, imagery, mobile surfaces, and purposeful motion.
- Research organized into 13 practitioner lenses, with primary sources and inspection limits.
- Five worked examples.
- Offline search across 13,351 attributed public references.
- An opaque-color contrast calculator.

The writing works without a shell. Optional bundled tools need Node.js 18+; linked previews need internet access. The current Skills CLI requires Node.js 22.20+.

Validation: nine automated checks pass; the downloadable archive was extracted into a clean folder and both tools executed successfully without npm dependencies. Repeated builds produce the same checksum. These checks cover packaging and tool behavior, not subjective design quality across models.

The ZIP contains no private projects, creator media, fonts, full essays, or source bundles. Original FORM writing and tooling are MIT licensed; third-party work retains its own terms.

Download assets:

- `form-design.zip`: the complete skill, approximately 1.5 MB.
- `form-design.zip.sha256`: checksum for the ZIP.
- `form-design.json`: release size, version, file count, reference count, and checksum.
